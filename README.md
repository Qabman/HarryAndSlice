# Harry & Slice wedding website

Static GitHub Pages version prepared for **Qabman/HarryAndSlice**.

## Publish

1. Upload all files in this folder to the root of the repository's `main` branch.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose **main** and **/(root)**.
4. Test **https://qabman.github.io/HarryAndSlice/** before changing the custom domain.
5. Add **harryandslice.co.uk** under **Custom domain** only after the test succeeds.

The `.nojekyll`, crawler-blocking `robots.txt`, and page-level `noindex` metadata are already included. GitHub will add the `CNAME` file when the custom domain is configured in Pages settings.
